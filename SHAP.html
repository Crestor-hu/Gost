Mean-centered logistic regression contributions (log-odds scale)

The calculator uses a fixed six-predictor logistic regression model. The bars show each predictor’s contribution to the model output relative to the derivation cohort, expressed on the log-odds scale rather than as changes in predicted probability. These coefficient-based contributions are not directly computed SHAP values. Red bars indicate positive contributions, while blue bars indicate negative contributions.

The 30% threshold is exploratory, while 53.48% was determined using the Youden index. These probability categories are intended for reference only.
